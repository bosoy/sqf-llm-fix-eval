# проверка модели на arma 3 (через mcp-сервер)

цель: оценить ту модель, которая сейчас подключена к этому чату. результат пишет сервер, оценок ты не видишь.

## порядок
1. узнай точное имя текущей модели. если не знаешь наверняка, спроси пользователя одним вопросом, не угадывай.
2. число прогонов: из запроса, иначе 3.
3. для каждого прогона:
   - вызови `get_task`, получишь талон и задачу
   - реши ее как обычную рабочую задачу, полный исправленный файл
   - вызови `submit_answer` с талоном, именем модели и файлом
   - каждый прогон делай в чистом контексте: субагент на той же модели или новый чат. если такой возможности нет, сделай один прогон и скажи пользователю повторить в новом чате
4. в конце вызови `get_results` и покажи сводку и путь к results.xlsx.
5. сразу после этого открой таблицу: прочитай `results.xlsx` (openpyxl или office-excel) и выведи лист «Прогоны» целиком как markdown-таблицу в ответе. Колонки: Модель, Прогон, Файл, т1–т5, Оценка, Условно, Лишние правки, Подозрительное, Стиль, Фрагмент. Оценка = сумма т1..т5, считай сам: формульные ячейки (Оценка, Строгая оценка) открытым чтением не вычисляются, не выводи формулу как значение.

## запреты
- не ищи и не читай файлы бенчмарка на диске, не подгоняй ответ
- один талон это один зачетный прогон, повторная сдача невозможна
- не пересказывай пользователю оценки отдельных прогонов, пока не сданы все; после теста показываешь таблицу целиком по пункту 5
