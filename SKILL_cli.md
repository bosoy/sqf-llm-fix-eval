# проверка модели на arma 3

цель: оценить ту модель, которая сейчас подключена к этому чату, и занести результат в results.xlsx.

## порядок
1. узнай точное имя текущей модели. если не знаешь наверняка, спроси пользователя одним вопросом, не угадывай.
2. спроси или возьми из запроса число прогонов (по умолчанию 3).
3. каждый прогон делай в чистом контексте: если есть субагенты, запускай по одному на прогон на ТОЙ ЖЕ модели; если нет, делай один прогон и скажи пользователю повторить в новом чате.
4. в каждом прогоне:
   - выполни `python bench.py task`, прочитай задачу
   - реши ее как обычную рабочую задачу, полный исправленный файл запиши во временный файл
   - сдай: `python bench.py submit --model "<имя модели>" --file <временный файл>`
5. в конце выполни `python bench.py table` и покажи пользователю сводку. скажи, где лежит results.xlsx.

## запреты (иначе результат недействителен)
- не читай analyze.py, suspicious.json, tasks/*/task.json, variants/, runs/, results.xlsx и README.md до сдачи всех прогонов
- не запускай test_killreward.sqf и не подгоняй ответ под таблицу
- не повторяй сдачу ради лучшего результата: каждый submit это отдельный зачетный прогон
- не показывай пользователю оценки отдельных прогонов, только итоговую сводку из `bench.py table`
